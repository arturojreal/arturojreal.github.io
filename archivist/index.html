About the project

Archivist started from a recurring problem: the moment you need to recall a specific accomplishment for a resume, interview, or performance review, the details are gone. The story was real and meaningful when it happened — but it was never written down, and memory fades fast.

The app is designed to remove every possible friction from the act of capturing. You don't need to structure anything — just describe what happened. Apple Intelligence handles the extraction, turning a rough narrative into a STAR-formatted archive entry that's immediately useful.

For users who want to extend the AI capabilities beyond what's on-device, Archivist supports bring-your-own API key for providers like OpenAI and Anthropic — keeping the architecture open without compromising the default privacy model.
