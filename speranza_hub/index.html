About the project

Speranza Hub grew out of a simple frustration: having to open ARC Raiders — or switch between community Discord servers and spreadsheets — just to know what's happening on the maps right now. The game's event system is deep and time-sensitive, and a glanceable widget felt like the obvious solution.

Event data is sourced from community-maintained APIs with a built-in fallback chain (MetaForge → Mahcks Data → hardcoded 24-hour UTC rotation), so the widget stays accurate even when one upstream source is unavailable. All event-to-icon mapping is handled locally, meaning the visual language stays consistent regardless of what the API returns.

The app is completely free. There are no ads, no subscriptions, and no data collection. An optional donation button is included for players who want to support development.

Speranza Hub is a fan-made community tool. It is not affiliated with, endorsed by, or associated with Embark Studios or ARC Raiders. All game data is sourced from community-maintained APIs. No copyrighted game assets are used.
