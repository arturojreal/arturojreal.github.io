About the project

Snapbooth started from a simple question: why does setting up a photobooth at an event require proprietary hardware, a subscription, or someone's personal device locked in a corner? The web already has everything needed — camera access, cloud storage, real-time delivery.

The entire stack is zero-build: plain HTML, vanilla JS modules, and Netlify serverless functions for the Cloudinary upload pipeline. Each event runs as its own isolated deployment with a private GitHub repo, its own Cloudinary environment, and a dedicated subdomain under snapbooth.photos.

The architecture keeps the codebase small and auditable, makes client deployments reproducible, and keeps all guest photo data scoped to the event — nothing shared, nothing leaked.
